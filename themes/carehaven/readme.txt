== Description ==

Carehaven is a WordPress Full Site Editing (FSE) block theme (`theme.json` v3) purpose-built for dental offices, orthodontists, oral surgeons, and outpatient clinics. Designed around clear clinical typography and local system font stacks with no external font requests.

Highlights:
* 3 Global Style Variations: Warm Practice (default), Crisp Multi-Clinic, and Cosmetic Studio.
* 13 Healthcare & Dental Block Patterns: Practice Hero, Coverage & Financing Strip, 6-Card Clinical Services Grid, Doctor Bio Profiles, Interactive Before/After Case Comparison, In-House Membership Plans, 4-Step First Visit Walkthrough, Patient Testimonials, Native FAQ Accordion, Appointment & Hours Section, and Full-Page Starters.
* Flexible Page Templates: Includes No-Title, Full-Width Canvas, Blank Canvas, Doctors Directory, and Services Hub templates.
* Thoughtful Defaults: Local system font stacks, keyboard-operable menus and comparison sliders, underlined content links, core skip-link support, and high-contrast color presets.

== Privacy ==

Carehaven does not collect, store, or transmit personal user data, telemetry, or analytics. All typography uses local system font stacks and all bundled vector illustrations are served directly from the theme directory.

== Frequently Asked Questions ==

= Does Carehaven load fonts from external servers? =
No. Carehaven uses local editorial serif and humanist sans system font stacks by default. You can also upload custom local font files anytime using the built-in WordPress Font Library.

= How do I build a full clinic homepage? =
Create a new page, assign the "Page — No Title" template, open the Block Inserter -> Patterns -> "Carehaven: Full Clinic Page Layouts", and insert the "Full Clinic Homepage Layout" pattern.
