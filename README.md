## How to Install

### Option 1: Download Ready-to-Install `.zip` (Recommended)
1. Visit **[https://nextrankhq.com/free-wordpress-themes](https://nextrankhq.com/free-wordpress-themes)** to browse all public themes and download the `.zip` package for the theme you want.
2. In your WordPress Admin dashboard, go to **Appearance → Themes → Add New Theme → Upload Theme**.
3. Select the downloaded `.zip` file, click **Install Now**, and click **Activate**.

### Option 2: Install from Source (`themes/` Directory)
1. Clone this repository:
   ```bash
   git clone https://github.com/NextRankHQ/free-wordpress-theme.git
   ```
2. Copy any theme folder from `themes/<theme-slug>` (for example, `themes/liberty-plumber` or `themes/carehaven`) into your WordPress installation's `wp-content/themes/` directory.
3. Activate the theme in **Appearance → Themes**.
